# Campus Complaint Portal (CCP)

A front-end Web Technology project for managing college complaints.

## Technologies
- HTML5
- CSS3
- Bootstrap 5
- Tailwind CSS
- JavaScript
- JSON
- AJAX/fetch-ready JSON data
- LocalStorage
- Git/GitHub Pages

## Run
Open `index.html` in a browser. For best results, use VS Code + Live Server.

## Demo Admin

## Student
Use Register to create a demo student account.

## Important
This is a front-end prototype. Complaint status updates work through browser LocalStorage. Data is not shared between different browsers/devices. A real deployment should use a backend/database.

## GitHub Pages
1. Create a GitHub repository.
2. Upload this folder.
3. Push to `main`.
4. In Settings -> Pages, select the `main` branch and root folder.
5. Save and open the generated Pages URL.
